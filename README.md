# Proposta TTD Syndex

Página para montar a proposta comercial de **abertura de TTD (Benefício ICMS)** da Syndex Logística e Gestão Aduaneira e baixar em PDF no padrão do timbrado.

## Como usar

1. Abra o link da página (GitHub Pages) no computador ou no celular.
2. Preencha uma vez o **Comercial responsável** com o seu nome — ele fica guardado no seu aparelho.
3. Preencha razão social, CNPJ, requerente (CPF opcional), valor da abertura de TTD e forma de pagamento.
4. Clique em **Baixar PDF**.

Os documentos necessários, as certificações, o logo e o rodapé já vêm no modelo.
O que cada pessoa digita fica só no navegador dela; nada é enviado para a internet.

## Como atualizar

Substitua o arquivo `index.html` por uma versão nova (mesmo nome) em **Add file > Upload files > Commit changes**.
Em alguns minutos o link passa a abrir a versão nova para todos.
